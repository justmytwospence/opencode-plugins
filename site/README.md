# OpenCode Plugins documentation

Independent static Astro/Starlight site. Production canonical: https://opencode-plugins.vercel.app.

```sh
cd site
npm ci
npm run check
npm run build
npm run dev
```

Use Node.js 22.12 or newer. Dependency changes follow the machine's npm release-age policy; never bypass it. The lockfile belongs to this directory, not a root workspace.

- `check`: compares the reference pages and the catalog (`src/data/plugins.mjs`) to the component directories under `../packages`; validates frontmatter, minimum reference structure, exact `::path:` install entries (terminal-only components through `cli.json`), JSON examples and local documentation links; rejects emojis and stale Pi or OpenCode 1 text; then runs Astro diagnostics.
- `build`: emits static `dist/`, builds the Pagefind search index, then checks rendered internal links and fragments, assets, canonical URLs, metadata, the labeled landing illustration and the search output.
- `dev`: local development server. Full search is generated by the production build.
- `preview`: serves the built output locally.

No backend adapter, credentials, model requests or runtime plugin imports are used. Fonts and search are served locally. External links are not fetched by checks.

## Authoring

Public pages live in `src/content/docs/`. Per-component reference filenames and the `plugin` frontmatter must match `packages/<name>`, and each reference carries the exact install entry `opencode-<name>@github:justmytwospence/opencode-plugins#<commit>::path:packages/opencode-<name>`. The catalog and navigation groups live in `src/data/plugins.mjs`; the root `scripts/test-contracts.mjs` compares it to `packages/` as well.

Keep requirements and optional integrations explicit, and verify every claim against the component's README, source and tests. Illustrations must be labeled as examples, not screenshots. No emojis.

The root repository owns CI and deployment. This package only produces static files; it does not configure or deploy a Vercel project, and it must not affect runtime installation of the plugins.
